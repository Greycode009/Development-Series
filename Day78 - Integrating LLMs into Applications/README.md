## Learning Notes

- **LLM vs GenAI application:** An LLM on its own only predicts text. A GenAI application wraps it with your own code — user input, prompts, business logic, and how the output is used.
- **Integration flow:** The app builds a prompt, sends it to the LLM through an API, receives the generated response, and then processes or displays it for the user.
- **Why it matters for an FDE:** Customers don't need a chatbot demo — they need an LLM working inside their existing product and workflows.
