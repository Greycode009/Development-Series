# Day 53 - Full-Stack Portfolio Website

## Project

**Full-Stack Portfolio Website**

Live Website: https://dipisha.vercel.app/

## Overview

On Day 53, I built a complete full-stack portfolio website for a friend.

The project includes both a frontend and backend, along with an admin panel that allows the website's content and data to be managed dynamically.

## What I Built

- Complete portfolio frontend
- Backend API
- Dynamic admin panel
- Website data management
- Real-world portfolio project
- Deployed the completed website

## Key Feature

The website is dynamically managed through the admin panel, allowing website data and content to be updated without manually changing the frontend code.
